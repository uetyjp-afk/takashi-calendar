# たかしのカレンダー

アイコンで予定を記録する、シンプルなカレンダーアプリ（PWA）。

- アイコン20種（病院・歯医者・食事・飲み会・仕事・誕生日・重要・映画・温泉・旅行・美容院・車・買い物・お薬・整体・早番・遅番・会議・スポーツ・お金）
- 下のアイコンバーは2段表示・横スクロール。ドラッグで日に置く、タップで入力画面
- 予定チップは長押しでメニュー（編集・移動・削除）、ドラッグで別日へ移動、ゴミ箱で削除
- Googleカレンダー連携：予定ごとの「Googleに追加」ボタンと、全体の .ics 書き出し
- データは端末の localStorage のみに保存。JSONバックアップ入出力つき
